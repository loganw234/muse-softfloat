**Mandated kernel shape (all ops):** decode with `src/msf_decode.h`
(`msf_decode`, exact sig×2^exp) → NaN delivery via
`msf_nan_delivery` (header records the SF-0 §2.5 reading; FMA order
= multiplicand, multiplier, addend) → special finite cases → exact
integer computation over `msf_u128` (`src/msf_wide.c`) → ONE
rounding via the pack for YOUR dest (`msf_pack_generic` with f16
parameters; you own dest=f16). No operation rounds twice; no
`float`/`double` types anywhere (the type scan refuses the words).
Where a Wave 1 parcel already solved the same shape at f32/f64,
mirror it at f16 widths and say so; deviations get a design-entry
line.
- add/sub: jam-align smaller significand to the larger exponent
  (`msf_u128_shr_jam`), add/subtract magnitudes by effective signs,
  pack once. Exact-zero rules per Clause 6.3 (x+(−x) is +0 except
  roundTowardNegative; −0 + −0 = −0).
- mul: `msf_u128_mul_u64_u64` (11×11 fits trivially; wider sources
  widen exactly); 0×∞ invalid via delivery helper with
  invalid_without_nan.
- div: exact long division producing ≥ p+2 quotient bits with the
  remainder as sticky evidence. Division-by-zero → §7.3.
- sqrt: integer sqrt at p+2 bits with exact remainder → sticky;
  negative (incl. −∞) invalid; sqrt(−0) = −0.
- fma: exact product, addend jam-aligned per WIDTHS.md, single
  pack; 0×∞ + quiet-NaN addend signals invalid and delivers the
  addend (caller raises invalid, helper delivers).
- remainder: exact x − n·y, n the ties-to-even integer; the defining
  relation r = x − n·y fixes nonzero signs (do not read any "sign of
  x" shorthand as overriding it); invalid only for x=∞ or y=0 (or
  NaN rules).
- roundToIntegral*: round in the significand domain; named forms
  signal no inexact; the Exact form signals inexact exactly when a
  nonzero fraction was discarded. sNaN via helper.
- nextUp/nextDown: adjacent encoding step (no flags except sNaN
  invalid); through ±0 to the smallest subnormal; maxFinite → ∞.
- scaleB: second operand is binary64 (logBFormat). Non-integral N
  truncates toward zero (project ruling; 5.3.3 leaves it
  language-defined); huge |N| may clamp internally since results
  saturate, but flags must come out of the pack. scaleB(±0,N)=±0,
  scaleB(±∞,N)=±∞, scaleB(x,0)=x (NaN rules first).
- logB: normalized exponent (subnormals count their leading zeros),
  delivered as binary64 (logBFormat); logB(±0) = −∞ +
  divisionByZero; logB(±∞) = +∞.
- convertFormat (dest f16): single rounding through pack; NaN via
  helper (sNaN invalid; payload truncate-to-default per §2.5);
  signed zeros preserved.
- from_int: exact magnitude → pack.
- to_int: project invalid rule in the header (saturate; NaN → 0) +
  invalid flag; inexact ONLY in the Exact variants.
- comparisons: 22 predicates from the four relations via
  `msf_cmp_finite` (exact, cross-format); signaling forms raise
  invalid on any NaN, quiet forms only on signaling NaN (§5.11).
- totalOrder/totalOrderMag: encoding-order keys within binary16,
  per Clause 5.10 (negative NaNs order by payload descending — the
  Wave 1 verifier note N1 confirmed this reading at f64).
