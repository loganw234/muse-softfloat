### Semantic pins (my restatement; brief frozen semantics second-read against survey 4.1/4.2 - agreement on every line)

Common 9.6: homogeneous same-format pair, same-format result, flags pointer required, invalid (MSF_FLAG_INVALID=0x01) is the only signal ever, from a signaling NaN operand only. Non-NaN value order: -inf < negative finite < -0 < +0 < positive finite < +inf. Signed zeros are ordered (-0 minimum, +0 maximum) - a deliberate tweak over msf_cmp_finite, which compares zeros equal; the tweak applies only when both operands are zeros (one-zero pairs already order correctly through msf_cmp_finite). Equal values otherwise (including same-sign zeros, same-sign infinities, identical finite): first operand wins, delivered verbatim.
Plain forms (minimum, maximum, minimumMagnitude, maximumMagnitude): any NaN operand delivers per the SF-0 2.5 matrix via msf_nan_delivery with invalid_without_nan=0 - first signaling operand quieted plus invalid, else first quiet operand, sign+payload preserved (same-format, so quieting sets the quiet bit and preserves the payload bits). No NaN: select by value (plain) or by magnitude (Magnitude).
Number forms (minimumNumber, maximumNumber, minimumMagnitudeNumber, maximumMagnitudeNumber): exactly one NaN operand delivers the other operand (the number, including zero/infinity) verbatim; a signaling NaN in that ignored position still signals invalid, a quiet NaN signals nothing - so msf_nan_delivery is NOT reused wholesale here; the core signals invalid itself when the single NaN is signaling and returns the number. Both operands NaN: the SF-0 2.5 matrix exactly as the plain forms. No NaN: same selection as the corresponding plain/Magnitude form.
Magnitude forms: compare magnitudes (sign-cleared encodings are monotone in magnitude for non-NaN binary interchange formats: zero < subnormal < normal < infinity). Smaller magnitude wins for minimumMagnitude(Number), larger for maximumMagnitude(Number). Magnitude tie breaks by the corresponding value form: minimumMagnitude ties deliver minimum(a,b), maximumMagnitude ties deliver maximum(a,b), each under the zero-order and first-wins rules above - so magnitude ties on (+x,-x) deliver -x / +x respectively, and (+0,-0) ties deliver -0 / +0.
No 2008 minNum-style aliases are added.

9.7 payloads: payload = trailing bits below the quiet bit = frac & (quiet_bit-1); widths/maxima: binary16 9 bits max 511, binary32 22 bits max 4194303, binary64 51 bits max 2251799813685247. No flags argument, never signal, string grammar untouched.
getPayload(a): a NaN (quiet or signaling, either sign - sign ignored) delivers the payload as the exact non-negative integral value in the same format (+0 for payload 0, e.g. the default quiet NaN); a non-NaN delivers -1 in the same format (sign set, biased exponent = bias, trailing zero). The integer encoding is built directly from the generated format constants (bit length, biased exponent, trailing shift); exact because payload+1 <= 2^(p-2)+... < 2^p, so no rounding is possible.
setPayload(a)/setPayloadSignaling(a): a is the same-format pattern (Step 0a table declaration). Admissible = finite, integral, in range: quiet form 0..max, signaling form 1..max. An admissible operand delivers a POSITIVE NaN: infinity pattern | quiet bit (quiet form only) | payload k; quiet k=0 is exactly MSF_F*_DEFAULT_QNAN. Anything else delivers +0 and signals nothing, including signaling-NaN input (msf_nan_delivery is not used here at all). Rulings pinned: +0 quiet-admissible as 0; -0 admissible-as-0 for the quiet form only, inadmissible (+0) for the signaling form; signaling form on +0 also delivers +0 (0 outside 1..max, would otherwise encode infinity). Negative nonzero, infinities, any NaN, non-integral finite (including every nonzero subnormal, all in (0,1) or (-1,0)), and integral values above max are inadmissible (+0). Integrality is tested on the decoded exact value sig*2^exp: exp>=0 is integral with bit length bitlen(sig)+exp (rejected when that exceeds the payload width, without overflow); exp<0 is integral iff the low -exp bits of sig are zero, value sig>>(-exp).
