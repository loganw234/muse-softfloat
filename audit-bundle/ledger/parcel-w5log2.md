### 3. Exact / tie branches and inexact obligations (enumerated)

Claim (tie completeness, spike Sec. 2.3 specialised): for
positive dyadic-rational w, log2(w) is either an integer
(w a power of two) or irrational. Proof: suppose
log2(w) = p/q rational, q >= 1. Write w = m*2^e with m an
odd positive integer. Then w^q = 2^p, i.e. m^q * 2^(eq) =
2^p; unique prime factorisation forces m^q to be a power
of two, and m odd forces m = 1. Hence w is a power of two
and log2(w) = e is an integer. Every rounding boundary of
a binary format (representable, midpoint of adjacents,
overflow midpoint, u/2 subnormal midpoint) is a dyadic
rational, so an irrational log2(w) equals none of them:
no exact result and no exact tie outside the power-of-two
branches, at any format, in any mode. In the power
branches the result is the integer k, and |k| is bounded
by the format: log2 k in [emin-p+1, emax] = f16 [-24,15],
f32 [-149,127], f64 [-1074,1023] (x=2^(emin-p+1) the
smallest subnormal); log2p1 w=1+x adds k=emax+1 only if
2^(emax+1) <= 1+fmax, i.e. never at f16/f32 (1+fmax <
2^(emax+1)) and at f64 w <= 1+(2-2^-52)2^1023 < 2^1024, so
k <= 1023 there too; low side w >= smallest positive (x
just above -1) gives k >= emin-p+1 likewise. Every such k
satisfies |k| < 2^11 <= 2^p, hence is itself representable:
the power branch is EXACT (never a midpoint delivery).
Consequences:

- THE TIE SET IS EMPTY for both functions (contrast
  Step 3a, where exp2(emin-p) and exp2m1(+- (p+1)) are
  true ties). A final-stage undecided therefore cannot be
  a tie artefact; spike R4 applies undiluted: any
  final-undecided > 0 is a STOP.
- Exact branches, enumerated: (E1) log2: x = 2^k -> k,
  no flags, INCLUDING subnormal x (x=2^-1074 -> -1074) and
  x=1 -> +0 (k=0, packed +0 exactly as Clause 9.2.1
  states). (E2) log2p1: 1+x = 2^k with x != 0 -> k, no
  flags (x=2^k-1 forms, e.g. x=-1/2 -> -1, x=1 -> 1). x=+-0
  is NOT routed here (k would be 0 and lose the -0 sign);
  it is the Sec. 2 specials row. No other exacts exist.
- Every kernel-path result (general path and log2p1 tiny
  path, x != 0) is irrational, hence inexact: the decide
  step ORs MSF_FLAG_INEXACT exactly as the explog/trig
  deciders do, and this is a proof. Tiny path has no
  hidden exact: |x| < 2^-8, x != 0 puts 1+x strictly
  between consecutive powers 2^-1..2^0..2^1 except 1
  itself, which needs x=0. Underflow remains the endpoint
  packs' agreed judgement (bits AND flags must agree).
- Poles: divideByZero only, no inexact (Sec. 2). Domain
  invalid: invalid only. Specials NaN/+inf/+-0(log2p1):
  per Sec. 2. No other flag sources exist; in particular
  overflow can never be raised by these two functions.

Exact-branch detection is integer-exact on the Sec. 4
materialisation (numerator big == 0), never on a rounded
wide value - so a truncated mm can never counterfeit an
exact (this is what the division-sticky negative control
attacks, Sec. 7).

### 4. Reduction, wide 1+x formation, tiny path

One general path serves both functions (spike Sec. 6.2):
materialise the argument w (w = x for log2, w = 1+x for
log2p1) EXACTLY as (Wint, wexp), value Wint * 2^wexp,
Wint a positive big integer in 40 limbs (1280 bits):

- log2: Wint = decoded sig (< 2^53, 2 limbs), wexp = d.exp.
  x > 0 is guaranteed here (Sec. 2 removed x<=0, inf, NaN).
- log2p1, x > 0: |x| = S*2^e. e >= 0: Wint = (S<<e)+1,
  wexp = 0 (bit span e+53 <= 1024). e < 0: Wint = 2^(-e)+S,
  wexp = e (span <= 1075 at f64 subnormal x).
- log2p1, x < 0: here -1 < x < 0 (pole/domain removed),
  so |x| < 1 and e < 0: Wint = 2^(-e)-S > 0, wexp = e
  (span <= 1075). Wint==0 would be exactly the x=-1 pole.

40 limbs hold every span above with margin (max 1075
bits). Then top = bit-length(Wint)-1, k0 = wexp+top,
mm = Wint/2^top in [1,2), w = 2^k0 * mm.

Recentring (exact, one compare, spike Sec. 6.2): mm^2 >= 2
iff Wint^2 >= 2^(2*top+1), computed as an exact big square
(used limbs squared into 80 limbs) compared against the
single-bit value. Equality is unattainable (mm dyadic,
sqrt2 irrational). If true: K = k0+1, reference REF=top+1
(mm' = mm/2 in [2^-1/2,1)); else K = k0, REF = top. Either
way mm_ref = Wint/2^REF lies in [2^-1/2, 2^1/2) and
log2(w) = K + t, t = log2(mm_ref), |t| <= 1/2.

Division inputs are formed SEPARATELY as exact bigs
NUM = |Wint - 2^REF|, DEN = Wint + 2^REF (s =
(mm_ref-1)/(mm_ref+1) = +- NUM/DEN, sign t_sign =
(Wint < 2^REF)). NUM==0 is exact branch E1/E2 (pack the
integer K exactly; K==0 packs +0). Forming NUM/DEN from
the exact bigs - never as (mm_wf - 1) - is load-bearing:
wf_normalize(NUM) keeps full RELATIVE precision at any
scale (NUM=1 at span 2^1022 for log2p1(x=2^1022) still
normalizes exactly), so the 971-bit attractor tail is a
composition fact, not a cancellation accident. Per-stage
wf conversion of NUM/DEN truncates below W bits; the
dropped low bits are THE sticky line of the s-division Ek
(Sec. 5, line L_sticky): identically zero for log2
(NUM/DEN < 2^55 < W) and charged in the shared EK_LOG for
log2p1, as the brief requires ("the line the sketch warns
not to forget").

log2p1 tiny path: |x| with floor(log2|x|) <= -9 (i.e.
|x| < 2^-8; the boundary |x|=2^-8 itself has w-span <= 61
bits and takes the general path exactly) bypasses w
formation: log2(1+x) = x * (1/ln2) * B(x), B(x) =
sum_{j>=0} (-x)^j/(j+1), computed relatively on |x| in wf
(x exact, <=53 bits): x<0 the all-positive Bp form
sum z^j/(j+1), x>0 the alternating Bm form (Horner
partials stay positive, terms decreasing - the D-series
shape Step 3a shipped). Result sign = sign(x), packed
PLAIN (no integer composition): this is the
identity-attractor path (spike Sec. 6.2; in-class RN max
62.07 needs ~110 correction-relative bits, stage 1).
Without it, w=1+x for subnormal-tiny x truncates mm to
exactly 1 at stage width and destroys directed sign - the
spike Sec. 2.4 collapse inside the kernel; the path split
is therefore correctness, not tuning. There is no cut of
Step-3a exponent-cut kind in this bundle: log results are
bounded and the pole neighbourhood (w smallest positive)
flows through the general path giving ~-1074, a normal
result (spike Sec. 6.2) - every "cut-like" threshold
(recentre, tiny threshold, pole equality) is an exact
integer test named above and gets +-ulp committed vectors.

Wide division `wf_div(out,a,b,n)`: a,b positive normalized
(or a zero -> zero). With M_a,M_b the W-bit significands:
if M_a >= M_b, quotient significand MQ = floor(M_a *
2^(W-1) / M_b), e_q = a.e-b.e; else MQ = floor(M_a * 2^W /
M_b), e_q = a.e-b.e-1; both give MQ in [2^(W-1),2^W) (the
bounds are one-line from normalization, checked in the
generator-side reasoning recorded here: ge case M_a>=M_b
gives MQ>=2^(W-1) and M_a<2^W, M_b>=2^(W-1) gives MQ<2^W;
lt case symmetric). The floor division is bit-by-bit
restoring division: remainder R (2n+1 limbs) starts as
M_a<<shift; for i=W-1..0, trial M_b<<i is compared and
subtracted - exact integer work, quotient is the true
floor. Error: 0 <= a/b - out < 1 ulp_W(out), relative <
2^(1-W) =: eps. No Newton seed, no convergence proof; the
price is W*(2n+1)-class limb ops (~5k at stage 1), inside
the Horner cost class. DEN in [1+2^-1/2, 1+2^1/2) after
recentring is never zero; NUM=0 never reaches division
(exact branch).

General kernel quantity (positive wf magnitude A with
proven |A-|t|| <= A*2^-EK_LOG[stage]):
s_mag = wf_div(wf(NUM), wf(DEN)); z = s^2;
A_s(z) = sum_{j=0}^{J-1} z^j/(2j+1) by Horner (coefficients
1/(2j+1) exact-rational floors); |t| = C2 * s * A_s,
C2 = (2/ln2) floor constant. |s| <= S := (sqrt2-1)/(sqrt2+1)
= 3-2sqrt2 = 0.171572875.. < Srat := 4143/24143 (rigorous:
sqrt2 < 14143/10000 since 14143^2 = 200024449 > 2*10000^2,
s increasing in mm, and |s(mm)| = |s(1/mm)| covers the low
side; the generator re-proves the integer check and uses
Srat). Z := Srat^2 < 0.0295.
